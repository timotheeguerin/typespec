Include experimental AI rules in generated linter reference documentation.
`LinterRuleRefDoc.rule` now also accepts `AiLinterRuleDefinition`. Consumers
that inspect execution callbacks must distinguish AI rules using
`"instructions" in rule`; common documentation metadata is unchanged.

```ts
export const $linter = defineLinter({ rules: [], aiRules: [myAiRule] });
```
